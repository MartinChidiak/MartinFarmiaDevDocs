## FarmIA local

- Checkout privado de DevDocs: `{{FARMIA_DOCS_ROOT}}`.
- Para alinear FarmIA con upstream, levantar el entorno, diagnosticar worktrees,
  Docker, puertos, Prisma, LocalStack o errores Windows como `spawn EINVAL`, usar
  la skill `farmia-local-maintenance` instalada desde ese checkout.
- Para decidir dónde guardar documentación, notas, configuración, dumps,
  secretos o skills, usar `farmia-documentation-routing`.
- Para trabajo funcional de Gestión, usar `farmia-gestion-operativa`.
- El código y las instrucciones del checkout activo de `farmia_app` prevalecen
  si una nota privada está desactualizada.
- La configuración local y los secretos nunca se copian a documentación ni Git.
